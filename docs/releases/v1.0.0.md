# V免签通知监听 v1.0.0

首个正式版本提供无需常驻 APK 的 KernelSU 收款通知监听服务。

## 主要功能

- 监听微信、企业微信和支付宝收款通知并投递到 V免签。
- 定时心跳、事件去重、失败重试队列和 supervisor 自动恢复。
- 全中文 KernelSU WebUI，支持动态状态、后台检测与控制、二维码配置和日志自动刷新。
- 服务运行与停止状态会同步到 KernelSU 模块描述。
- 日志限制大小、脱敏显示，并在 WebUI 中将最新记录置顶。

## 兼容性

- `arm64-v8a`
- Android API 35
- KernelSU

## 安装

下载 `vmq-ksu-v1.0.0-arm64-api35.zip` 和同名 `.sha256`，校验 SHA256 后在 KernelSU 管理器中从本地安装并重启设备。随后打开模块 WebUI，填写 V免签服务地址与通信密钥，保存配置并执行“检测心跳”和“检测监听”。

升级或排障前请备份必要配置。不要公开通信密钥、支付数据或原始运行日志。
